# 🐾 S.O.S Patinhas

O **S.O.S Patinhas** é um projeto acadêmico desenvolvido na **FATEC Ourinhos**, para a disciplina de **Engenharia de Software**.

A proposta é oferecer uma plataforma web para apoiar a causa animal, facilitando a divulgação de animais para adoção e a organização de atividades de uma ONG.

## Sobre o projeto

O site reúne informações sobre adoção, denúncias, resgates, doações e voluntariado, além de contar com um painel administrativo para a equipe responsável.

## Tecnologias utilizadas

**Python • FastAPI • SQLite • HTML • CSS • JavaScript**

## Como executar

No Linux (Zorin OS, Ubuntu ou Mint), abra o terminal na pasta do projeto e execute:

```bash
sudo apt install -y python3 python3-venv python3-pip
bash iniciar.sh
```

Acesse **http://127.0.0.1:8000** no navegador.

Para criar um administrador ou adicionar animais fictícios para demonstração:

```bash
bash iniciar.sh admin
bash iniciar.sh demo
```

## Observação

Este é um **projeto acadêmico de demonstração**. Os animais cadastrados pelo modo de demonstração são fictícios.
