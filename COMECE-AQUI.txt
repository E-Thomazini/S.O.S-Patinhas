SOS PATINHAS — INSTALAÇÃO NO ZORIN OS
===================================

1. Extraia o ZIP e entre na pasta SOS-Patinhas-Site.
2. Abra a pasta no terminal.
3. Se precisar: sudo apt install -y python3 python3-pip python3-venv
4. Execute: bash iniciar.sh demo    (4 animais FICTÍCIOS opcionais)
5. Execute: bash iniciar.sh admin   (cria administrador)
6. Execute: bash iniciar.sh         (abre site)
7. Navegador: http://127.0.0.1:8000

O iniciador cria um ambiente virtual .venv e não altera o Python global.

SE JÁ USAVA OUTRA VERSÃO:
- Antes de atualizar, pare o site (Ctrl+C).
- FAÇA BACKUP: sos_patinhas.db, .env, static/uploads/ e private/.
- Extraia a nova versão por cima sem apagar esses itens.
- Execute bash iniciar.sh. Migrações do banco são incrementais.

Pix está DESABILITADO até ser configurado com chave oficial.
Veja as configurações em README.md e .env.example.

Fotos da demonstração são fotorrealistas geradas por IA e representam
animais FICTÍCIOS, não animais verdadeiros disponíveis para adoção.

Não publique dados reais no GitHub. Leia FUNCIONALIDADES.md e
ALINHAMENTO_DOCUMENTACAO.md para detalhes de requisitos e pendências.
